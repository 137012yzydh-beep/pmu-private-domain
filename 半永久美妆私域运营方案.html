一、行业诊断：为什么半永久美妆必须做私域

1.1 行业特性分析

维度特征私域意义
消费频次低频（纹绣 1-3 年/次）必须靠衍生品+裂变拉长 LTV
客单价高客单（¥800-3000）决策链路长，需大量信任铺垫
信任门槛极高（做在脸上）术后护理质量决定信任度
社交属性强（效果可见）老带新获客成本趋近于 0
衍生品机会修复产品/护肤品/工具高频消耗品拉升 LTV 数倍

1.2 核心矛盾

低频纹绣（1-3年/次）+ 高获客成本（¥100-300/人）→ 不加私域，用户做完就走，LTV ≈ 单次客单价 → 私域目标：把 LTV 从 ¥1000-3000 拉到 ¥5000-8000+

1.3 LTV 拆解模型

单客 LTV = 首次纹绣(¥1280) + 修复产品(¥300) + 补色(¥800) + 新项目(¥1500) + 衍生品(¥2000) + 老带新价值(¥500-2000)

私域做好后单客 LTV 可达 ¥5000-8000，vs 不做私域仅 ¥1280-2000。

生日祝福+专属折扣(前3天) → 社群@祝福(当天)

十、常见坑 & 避坑指南

  1. 加完好友就群发广告 → 用户秒删。必须先给价值（护理知识/案例），再谈转化。
  2. 建大群塞所有人 → 死的快。按阶段分群，术后护理小群 + 兴趣大群 + VIP 小群。
  3. 社群只有促销没有内容 → 退群率高。严格执行 70% 价值内容红线。
  4. 术后护理敷衍 → 错过建立信任的黄金窗口。术后 14 天决定用户未来 3 年的价值。
  5. 只做纹绣不想衍生品 → LTV 天花板低。修复产品、护肤品、补色、新项目要一起做。
  6. 忽视老带新 → 浪费了半永久美妆天然适合裂变的属性。
  7. 过度依赖自动化 → 术后护理和问题回复必须有人工介入，纯机器回复让用户觉得被敷衍。
  8. 不关注退群/删除数据 → 退群率是最直接的体验指标，每周必须关注。

十一、计算你的私域天花板

假设门店每月到店 100 位新客：

不加私域：100人 × ¥1500 = ¥150,000/月，全年 LTV ≈ ¥1500/人
加私域（保守估计）：60人进私域池 → 修复产品 ¥5,400 + 补色 ¥19,200 + 新项目 ¥13,500 + 推荐新客 ¥22,500 = 私域增量 ¥60,600/月。单客 LTV = ¥1500 + ¥1010 = ¥2,510（+67%）
加私域（理想状态）：配合裂变 + 多次复购 + VIP 转化，单客 LTV 可达 ¥5,000-8,000（+233%-433%）

这就是私域的复利效应——前期投入基建成本，后期每多一个客户都是在为资产池做加法。
